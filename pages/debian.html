Already on Debian testing?

Add the Unbound archive and install from apt. Updates then arrive with the rest of your system.

1. Install the archive key

wget https://github.com/unbound-linux/apt/releases/latest/download/unbound-archive-keyring.deb
sudo apt install ./unbound-archive-keyring.deb

2. Add the apt source

echo "deb [signed-by=/usr/share/keyrings/unbound-archive-keyring.pgp] https://unbound-linux.github.io/apt rolling main" \
  | sudo tee /etc/apt/sources.list.d/unbound.list
sudo apt update

On a Mac mini M2, use rolling main apple: the apple component carries the Apple Silicon kernel.

3. Install

sudo apt install unbound-desktop

The desktop only. Pick Unbound at your login screen.

sudo apt install unbound-os

The whole system as on the install media: the desktop, its login screen and the system defaults that go with it.
