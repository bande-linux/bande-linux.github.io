Already on Debian testing?

Add the Bande archive and install from apt. Updates then arrive with the rest of your system.

1. Add the Bande archive

cd /tmp
wget https://github.com/bande-linux/apt/releases/latest/download/bande-archive-keyring.deb \
     https://github.com/bande-linux/apt/releases/latest/download/bande-apt-source.deb
sudo apt install ./bande-archive-keyring.deb ./bande-apt-source.deb
sudo apt update

2. Install

sudo apt install bande-desktop

The whole system as on the install media: the desktop, its login screen, networking, sound and the everyday apps. If you already have a login screen such as GDM, apt asks which one to use. Add --no-install-recommends for just the desktop and a way to log in.
