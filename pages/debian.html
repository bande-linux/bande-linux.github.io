Already on Debian testing?

Add the Bande archive and install from apt. Updates then arrive with the rest of your system.

1. Install the archive key

wget https://github.com/bande-linux/apt/releases/latest/download/bande-archive-keyring.deb
sudo apt install ./bande-archive-keyring.deb

2. Add the apt source

echo "deb [signed-by=/usr/share/keyrings/bande-archive-keyring.pgp] https://bande-linux.github.io/apt rolling main" \
  | sudo tee /etc/apt/sources.list.d/bande.list
sudo apt update

On a Mac mini M2, use rolling main apple: the apple component carries the Apple Silicon kernel.

3. Install

sudo apt install bande-desktop

The desktop only. Pick Bande at your login screen.

sudo apt install bande-os

The whole system as on the install media: the desktop, its login screen and the system defaults that go with it.
