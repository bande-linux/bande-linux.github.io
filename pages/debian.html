Install on Debian testing

Bande is installed from its APT repository at bande-linux.github.io/apt. It supports Debian testing only, on amd64 and arm64. It does not install on Debian 13 (trixie).

1. Add the repository

Download the keyring and source packages from the latest release of the apt repository and install them:

cd /tmp
wget https://github.com/bande-linux/apt/releases/latest/download/bande-archive-keyring.deb \
     https://github.com/bande-linux/apt/releases/latest/download/bande-apt-source.deb
sudo apt install ./bande-archive-keyring.deb ./bande-apt-source.deb

2. Install the desktop

sudo apt update
sudo apt install bande-desktop

If another display manager is installed, debconf asks which one to start. To change it later, run sudo dpkg-reconfigure greetd. At login, select the Bande session.

What is installed

bande-desktop depends on the compositor, shell, lock screen, session services, the desktop portal and PipeWire, and on a login manager: the Bande login window under greetd, or an existing one.

It recommends:

  • The Bande login window, Files, Settings, screenshots, automount, the file chooser and the polkit agent.
  • NetworkManager, PackageKit, CUPS, GNOME Keyring, zram swap and systemd-oomd.
  • The Bande apps Terminal, Software, Package Installer and Activity Monitor.
  • bande-apt-source, so the system follows Bande releases.

For the desktop, a login manager and sound only:

sudo apt install --no-install-recommends bande-desktop

No Debian apps are recommended; install a browser, viewers and editors from Software. Mail and Calendar are not recommended either. Install them separately:

sudo apt install bande-mail bande-calendar

Updates

Updates come with the rest of the system:

sudo apt update
sudo apt upgrade

Settings > Software Update does the same.

Removal

sudo apt purge bande-desktop
sudo apt autoremove
sudo apt purge bande-apt-source bande-archive-keyring

Signing key

The archive key and its fingerprint are on the repository page. If apt update reports a signature error after a key change, repeat step 1.
