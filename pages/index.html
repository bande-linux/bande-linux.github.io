Bande

Bande is a Wayland desktop environment for Debian, written in Rust. It has its own compositor, shell, session services and applications. It runs on amd64 and arm64.

Bande targets Debian 14 (forky). It follows forky through Debian testing and aims to be ready when forky is released as stable. It is in early development and not yet suitable as a main system.

Requirements

  • Debian 14 (forky), amd64 or arm64. Debian 13 (trixie) and older releases are not supported.
  • Wayland only. There is no X11 or XWayland, so X11-only programs do not run.

Installation

  • Install on Debian 14 from the Bande APT repository.
  • Install media for amd64 and arm64.

Source code

  • desktop: the desktop environment and bande-desktop
  • apps: the Bande applications
  • apt: the APT repository
  • web: Bande Browser, Debian's firefox-esr with Bande's changes
  • images: install media
