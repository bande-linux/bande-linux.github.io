Bande

Bande is a desktop environment for Debian testing on amd64 and arm64. It has its own Wayland compositor, shell, session services and applications, written in Rust.

Bande is in early development. It is not yet suitable as a main system.

Requirements

  • Debian testing, amd64 or arm64.
  • Debian 13 (trixie) and other stable releases are not supported. The packages are built against the C library in testing and do not install on stable.
  • Wayland only. There is no X11 or XWayland, so X11-only programs do not run.

Installation

  • Install on Debian testing from the Bande APT repository.
  • Mac mini M2: kernel and hardware status.
  • Install media: not published yet.

Source code

  • desktop: the desktop environment and bande-desktop
  • apps: Terminal, Activity Monitor, Software, Package Installer, Mail, Calendar
  • apt: the APT repository
  • kernel: Debian's kernel with the Mac mini M2 patches
  • web: the web engine for the Browser app (not released)
