Mac mini M2

Bande runs on the Apple Mac mini M2 (2023, J473) with Debian's kernel and the Bande patches for Apple hardware. Hardware support is incomplete. Other Apple Silicon machines are not supported.

Kernel

The kernel repository builds Debian testing's linux source with the Bande patches as the apple-arm64-16k flavour. A new build follows each new kernel in testing. The packages are published in the apple component of the APT repository (arm64 only).

bande-os-apple installs bande-desktop and this kernel, and pins Debian's own kernels, which do not run on this machine.

Installation

The Mac needs a boot chain installed from macOS. The installer for it is not published yet; see Download. On a Mac mini M2 that already runs Debian testing, add the repository as described in Install on Debian testing (on the Mac it adds the apple component too), then run:

sudo apt install bande-os-apple
